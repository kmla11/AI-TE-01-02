# Multi-Agent System (MAS) Simulation

Modul ini berisi implementasi simulasi sederhana dari sebuah **Sistem Multi-Agen (Multi-Agent System)** menggunakan bahasa pemrograman Python.

---

## 1. Introduction
Sistem Multi-Agen adalah sistem yang terdiri dari beberapa agen otonom yang saling berinteraksi dan bekerja sama di dalam suatu lingkungan (*environment*) untuk mencapai tujuan bersama atau menyelesaikan tugas tertentu. Di dalam program ini, disimulasikan dua agen dengan peran berbeda—yaitu agen pengumpul data dan agen analis—yang berinteraksi melalui objek lingkungan bersama.

---

## 2. Requirements
Untuk menjalankan program simulasi ini, pastikan Anda telah menyiapkan:
* **Python** (Versi 3.x direkomendasikan).
* **Visual Studio Code (VS Code)** atau editor teks lainnya.

*(Tidak memerlukan instalasi library pihak ketiga/eksternal).*

---

## 3. How to Use
1. Buka folder proyek utama Anda di **VS Code**.
2. Pastikan file kode utama untuk multi-agen (misalnya `agent.py`) sudah berada di dalam folder `Multi_Agent_System`.
3. Buka file tersebut untuk melihat struktur kelas `Environment` dan `Agent` yang digunakan.

---

## 4. Running
Buka terminal internal di VS Code, lalu jalankan program dengan perintah berikut:

```bash
python Multi_Agent_System/agent.py
